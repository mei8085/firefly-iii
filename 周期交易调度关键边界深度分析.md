# Firefly III 周期交易调度关键边界深度分析

## 引言

本报告针对周期交易调度系统中的三个核心边界问题进行深入剖析：

1. **12小时间隔放行后为何会直接触发生成动作**
2. **周末顺延为何要多算两天**
3. **后续怎样挡住重复生成**

## 问题一：12小时间隔放行后为何会直接触发生成动作

### 1.1 调度放行机制

**文件位置**：[RecurringCronjob.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Support/Cronjobs/RecurringCronjob.php)

#### 时间间隔检查逻辑

```php
// 第47-73行
$config        = FireflyConfig::get('last_rt_job', 0);
$lastTime      = (int) $config->data;
$diff          = now(config('app.timezone'))->getTimestamp() - $lastTime;

if (0 === $lastTime) {
    Log::info('Recurring transactions cron-job has never fired before.');
}
// less than half a day ago (43,200秒 = 12小时):
if ($lastTime > 0 && $diff <= 43_200) {
    Log::info(sprintf('It has been "%s" since the recurring transactions cron-job has fired.', $diffForHumans));
    if (false === $this->force) {
        // 未超过12小时且非强制模式，直接返回，不执行
        $this->message = sprintf('It has been "%s" since the recurring transactions cron-job has fired. It will not fire now.', $diffForHumans);
        $this->jobFired = false;
        return;
    }
    Log::info('Execution of the recurring transaction cron-job has been FORCED.');
}

if ($lastTime > 0 && $diff > 43_200) {
    Log::info(sprintf('It has been "%s" since the recurring transactions cron-job has fired. It will fire now!', $diffForHumans));
}
```

#### 放行后的直接触发

```php
// 第75行 - 无条件执行
$this->fireRecurring();
```

**关键机制分析**：

| 条件 | 结果 |
|------|------|
| `$lastTime == 0` | 首次执行，放行并继续 |
| `$diff <= 43200 && !$force` | 未超过12小时，**直接return退出** |
| `$diff <= 43200 && $force` | 强制执行，放行并继续 |
| `$diff > 43200` | 超过12小时，放行并继续 |

### 1.2 直接触发生成的关键代码

```php
// 第80-97行 - fireRecurring() 方法
private function fireRecurring(): void
{
    Log::info(sprintf('Will now fire recurring cron job task for date "%s".', $this->date->format('Y-m-d H:i:s')));

    $job                = new CreateRecurringTransactions($this->date);
    $job->setForce($this->force);
    $job->handle();  // ⚠️ 关键：直接调用 handle()，而非 dispatch()

    $this->jobFired     = true;
    $this->jobErrored   = false;
    $this->jobSucceeded = true;
    $this->message      = 'Recurring transactions cron job fired successfully.';

    FireflyConfig::set('last_rt_job', (int) $this->date->format('U'));
    Log::info(sprintf('Marked the last time this job has run as "%s" (%d)', $this->date->format('Y-m-d H:i:s'), (int) $this->date->format('U')));
    Log::info('Done with recurring cron job task.');
}
```

**核心发现**：`$job->handle()` 是**同步调用**，而非 `dispatch($job)` 的异步分发。这意味着：

1. **同步执行**：放行后立即执行，不经过队列
2. **阻塞等待**：直到所有交易生成完成才返回
3. **状态立即更新**：执行完成后立即更新 `last_rt_job` 配置

### 1.3 设计意图

这种设计的原因：

| 设计考量 | 说明 |
|---------|------|
| **Cron 场景适配** | 定时任务本身就是异步的，不需要额外队列 |
| **事务完整性** | 确保所有交易在单次 cron 执行中完成 |
| **状态一致性** | 执行完成后立即更新时间戳，防止重复触发 |
| **日志追踪** | 完整的执行日志可以在单次调用中记录 |

## 问题二：周末顺延为何要多算两天

### 2.1 问题背景

**文件位置**：[CreateRecurringTransactions.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Jobs/CreateRecurringTransactions.php#L365-L369)

```php
// 第365-369行
// start looping from $startDate to today perhaps we have a hit?
// add two days to $this->date, so we always include the weekend.
$includeWeekend = clone $this->date;
$includeWeekend->addDays(2);
$occurrences    = $this->repository->getOccurrencesInRange($repetition, $recurrence->first_date, $includeWeekend);
```

### 2.2 核心原因：周末顺延场景

假设当前日期是 **周五（2024-01-19）**：

| 场景 | 原始日期 | 顺延策略 | 实际执行日期 |
|------|---------|---------|------------|
| 周末日期 | 周六（2024-01-20） | 顺延到周五 | **周五（2024-01-19）** |
| 周末日期 | 周日（2024-01-21） | 顺延到周五 | **周五（2024-01-19）** |
| 周末日期 | 周日（2024-01-21） | 顺延到周一 | **周一（2024-01-22）** |

**关键发现**：

1. **提前覆盖**：如果交易日期是周六或周日，但配置为"顺延到周五"，需要在周五就计算到这些日期
2. **延后覆盖**：如果配置为"顺延到周一"，需要包含周一的日期

### 2.3 两天的计算逻辑

```text
┌─────────────────────────────────────────────────────────────────┐
│                    日期范围计算示意图                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   今天          +1天         +2天                               │
│    │              │            │                               │
│    ▼              ▼            ▼                               │
│   周五 ──────── 周六 ──────── 周日 ──────── 周一               │
│   (今天)         (周末)        (周末)        (顺延目标)         │
│                                                                 │
│   计算范围: [first_date, 今天+2天]                              │
│   即: [first_date, 周日]                                        │
│                                                                 │
│   场景1: 周六交易, 顺延到周五 → 在周五执行时需要计算到周六        │
│   场景2: 周日交易, 顺延到周五 → 在周五执行时需要计算到周日        │
│   场景3: 周日交易, 顺延到周一 → 在周一执行时需要计算到周一        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.4 周末过滤逻辑验证

**文件位置**：[FiltersWeekends.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Support/Repositories/Recurring/FiltersWeekends.php#L41-L99)

```php
protected function filterWeekends(RecurrenceRepetition $repetition, array $dates): array
{
    // 不处理周末
    if (RecurrenceRepetitionWeekend::WEEKEND_DO_NOTHING->value === $repetition->weekend) {
        return $dates;
    }
    
    foreach ($dates as $date) {
        if ($date->isWeekend()) {
            // 移动到周五
            if (RecurrenceRepetitionWeekend::WEEKEND_TO_FRIDAY->value === $repetition->weekend) {
                $clone->addDays(5 - $date->dayOfWeekIso);
            }
            // 移动到周一
            if (RecurrenceRepetitionWeekend::WEEKEND_TO_MONDAY->value === $repetition->weekend) {
                $clone->addDays(8 - $date->dayOfWeekIso);
            }
        }
    }
    return $return;
}
```

**验证逻辑**：

| 原始日期 | dayOfWeekIso | 顺延到周五 | 顺延到周一 |
|---------|-------------|-----------|-----------|
| 周六 | 6 | 6 → 6 + (5-6) = 5 → 周五 | 6 → 6 + (8-6) = 8 → 周一 |
| 周日 | 7 | 7 → 7 + (5-7) = 5 → 周五 | 7 → 7 + (8-7) = 8 → 周一 |

### 2.5 设计意图总结

```text
┌─────────────────────────────────────────────────────────────────┐
│                    为何需要 +2 天?                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   假设今天是周五:                                                │
│                                                                 │
│   计算范围 = [first_date, 今天] = [first_date, 周五]            │
│   → 只能计算到周五之前的日期                                      │
│   → 如果交易日期是周六/周日且顺延到周五，就会漏掉!                  │
│                                                                 │
│   计算范围 = [first_date, 今天+2天] = [first_date, 周日]         │
│   → 包含周六和周日                                               │
│   → 周末过滤后会顺延到周五，正好在今天执行                        │
│                                                                 │
│   假设今天是周一:                                                │
│                                                                 │
│   计算范围 = [first_date, 今天+2天] = [first_date, 周三]         │
│   → 如果周日的交易顺延到周一，周一执行时能正确计算                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

```php
public function getJournalCount(Recurrence $recurrence, ?Carbon $start = null, ?Carbon $end = null): int
{
    $query = TransactionJournal::leftJoin('journal_meta', 'journal_meta.transaction_journal_id', '=', 'transaction_journals.id')
        ->where('transaction_journals.user_id', $recurrence->user_id)
        ->whereNull('transaction_journals.deleted_at')
        ->where('journal_meta.name', 'recurrence_id')
        ->where('journal_meta.data', '"'.$recurrence->id.'"')
    ;
    if ($start instanceof Carbon) {
        $query->where('transaction_journals.date', '>=', $start->format('Y-m-d 00:00:00'));
    }
    if ($end instanceof Carbon) {
        $query->where('transaction_journals.date', '<=', $end->format('Y-m-d 00:00:00'));
    }
    return $query->count('transaction_journals.id');
}
```

```php
public function createdPreviously(Recurrence $recurrence, Carbon $date): bool
{
    // 查询所有属于此周期交易的 journal
    $set = TransactionJournalMeta::where(static function (Builder $q1) use ($recurrence): void {
        $q1->where('name', 'recurrence_id');
        $q1->where('data', json_encode((string) $recurrence->id));
    })->get(['journal_meta.transaction_journal_id']);

    // 检查其中是否有今天日期的记录
    foreach ($set as $journalMeta) {
        $count = TransactionJournalMeta::where(static function (Builder $q2) use ($date): void {
            $string = (string) $date;
            $q2->where('name', 'recurrence_date');
            $q2->where('data', json_encode($string));
        })->where('transaction_journal_id', $journalMeta->transaction_journal_id)->count();
        if ($count > 0) {
            return true;
        }
    }
    return false;
}
```

### 3.6 额外防护：validRecurrence 过滤

**文件位置**：[CreateRecurringTransactions.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Jobs/CreateRecurringTransactions.php#L412-L464)

```php
private function validRecurrence(Recurrence $recurrence): bool
{
    // 检查是否活跃
    if (!$this->active($recurrence)) {
        return false;
    }

    // 检查重复次数限制
    $journalCount = $this->repository->getJournalCount($recurrence);
    if (0 !== $recurrence->repetitions && $journalCount >= $recurrence->repetitions && false === $this->force) {
        return false;
    }

    // 检查结束日期
    if ($this->repeatUntilHasPassed($recurrence)) {
        return false;
    }

    // 检查开始日期
    if ($this->hasNotStartedYet($recurrence)) {
        return false;
    }

    // 检查今日是否已执行
    if (false === $this->force && $this->hasFiredToday($recurrence)) {
        Log::info(sprintf('Recurrence #%d has already fired today. Skipped.', $recurrence->id));
        return false;
    }

    return true;
}
```

**hasFiredToday 检查**（第383-386行）：

```php
private function hasFiredToday(Recurrence $recurrence): bool
{
    return null !== $recurrence->latest_date && $recurrence->latest_date->eq($this->date);
}
```

### 3.7 防重复机制总结

| 层级 | 检查内容 | 数据来源 | 触发时机 |
|------|---------|---------|---------|
| **过滤层** | `validRecurrence()` | Recurrence 模型状态 | 循环前批量过滤 |
| **日期层** | `$date->ne($this->date)` | 日期比较 | 单个事件处理 |
| **计数层** | `getJournalCount()` | TransactionJournal + journal_meta | 单个事件处理 |
| **元数据层** | `createdPreviously()` | journal_meta 记录 | 单个事件处理 |
| **状态层** | `latest_date` 更新 | Recurrence 模型 | 创建成功后 |
