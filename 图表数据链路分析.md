# Firefly III 图表数据链路分析

## 一、系统架构概览

Firefly III 存在两套图表系统：

| 版本 | 技术栈 | 路由前缀 | 主要用途 |
|------|--------|----------|----------|
| v1   | jQuery + Chart.js + Twig 模板 | `/chart/*` | 传统管理界面图表 |
| v2   | Vue + Chart.js + Axios | `/api/v1/chart/*` | 新版仪表盘图表 |

## 四、时间区间处理机制

### 4.1 时间粒度自动计算

[WholePeriodChartGenerator::calculateStep](file:///d:/fz/0601-1/solo-dogfeeding/code/79-firefly-iii/app/Support/Chart/Category/WholePeriodChartGenerator.php#L124-L139)

```php
protected function calculateStep(Carbon $start, Carbon $end): string
{
    $step   = '1D';  // 默认按天
    $months = $start->diffInMonths($end, true);
    
    if ($months > 3)    $step = '1W';  // 超过3个月按周
    if ($months > 24)   $step = '1M';  // 超过2年按月
    if ($months > 100)  return '1Y';   // 超过8年按年
    
    return $step;
}
```

### 4.2 时间区间列表生成

[Navigation::listOfPeriods](file:///d:/fz/0601-1/solo-dogfeeding/code/79-firefly-iii/app/Support/Navigation.php#L446-L478)

```php
public function listOfPeriods(Carbon $start, Carbon $end): array
{
    $diff = $start->diffInMonths($end, true);
    
    // 根据时间跨度决定增量单位
    if ($diff < 1) {
        $increment = 'addDay';           // <1个月: 按天
        $displayFormat = 'MM-DD';
    } elseif ($diff < 12) {
        $increment = 'addMonthsNoOverflow'; // 1-12个月: 按月
        $displayFormat = 'YYYY-MM';
    } else {
        $increment = 'addYear';           // >12个月: 按年
        $displayFormat = 'YYYY';
    }
    
    // 生成区间列表
    $entries = [];
    while ($begin < $end) {
        $entries[$begin->format('Y-m-d')] = $begin->isoFormat($displayFormat);
        $begin->{$increment}();
    }
    
    return $entries;
}
```

### 4.3 时间区间变化时的重新计算流程

**触发时机**：
1. 用户切换视图范围（月/季/年/自定义）
2. 前端 `window.store.observe('end')` 监听到变化
3. 调用对应 API 重新获取数据

**完整流程**：

```
前端时间选择器变化
    ↓
window.store 更新 'start' / 'end'
    ↓
观察者触发（categories.js line 211-217）
    ↓
chartData = null  // 清除本地缓存
    ↓
getFreshData() 调用 API
    ↓
URL 参数更新: ?start=2024-01-01&end=2024-03-31
    ↓
后端接收请求
    ↓
CacheProperties 哈希变化（时间参数参与哈希计算）
    ↓
缓存未命中，重新生成数据
    ├─ 重新计算时间粒度（calculateStep）
    ├─ 重新生成时间区间（listOfPeriods）
    └─ 按新区间重新查询聚合数据
    ↓
返回新图表数据
    ↓
前端调用 chart.update() 更新渲染
```

### 4.4 时间参数参与缓存键计算

[CacheProperties::hash](file:///d:/fz/0601-1/solo-dogfeeding/code/79-firefly-iii/app/Support/CacheProperties.php#L92-L104)

```php
private function hash(): void
{
    $content = '';
    foreach ($this->properties as $property) {
        // $start 和 $end 作为属性参与 JSON 编码
        $content .= json_encode($property);
    }
    // 生成 16 位 SHA256 哈希作为缓存键
    $this->hash = substr(hash('sha256', $content), 0, 16);
}
```

**缓存键包含参数**：
- 用户 ID
- 最后活动时间（数据变更时失效）
- `start` 开始时间
- `end` 结束时间
- 分类 ID / 账户 ID 等维度参数
- `convertToPrimary` 主货币转换标志

private function reportPeriodChart($accounts, $start, $end, ?Category $category): array
{
    // 1. 根据分类是否存在，选择不同 Repository
    if (!$category) {
        // 未分类交易
        $expenses = $this->noCatRepository->listExpenses($start, $end, $accounts);

    } else {

        $expenses = $this->opsRepository->listExpenses($start, $end, $accounts, $collection);
        $income   = $this->opsRepository->listIncome($start, $end, $accounts, $collection);
    }
    
    // 2. 获取涉及的所有货币
    $currencies = array_unique(array_merge(array_keys($income), array_keys($expenses)));
    
    // 3. 获取时间区间列表
    $periods = Navigation::listOfPeriods($start, $end);
    
    // 4. 为每种货币创建收支两个数据集
    foreach ($currencies as $currencyId) {
        // 初始化空数据
        foreach (array_keys($periods) as $period) {
            $chartData[$outKey]['entries'][$label] = '0';
            $chartData[$inKey]['entries'][$label]  = '0';
        }
        
        // 填充支出数据
        foreach ($outSet['transaction_journals'] as $journal) {
            $date = $journal['date']->isoFormat($format);
            $chartData[$outKey]['entries'][$date] = bcadd($amount, $chartData[$outKey]['entries'][$date]);
        }
        
        // 填充收入数据
        foreach ($inSet['transaction_journals'] as $journal) {
            $date = $journal['date']->isoFormat($format);
            $chartData[$inKey]['entries'][$date] = bcadd($amount, $chartData[$inKey]['entries'][$date]);

### 6.2 v2 现代前端（Alpine.js + Chart.js）

入口：[categories.js](file:///d:/fz/0601-1/solo-dogfeeding/code/79-firefly-iii/resources/assets/v2/src/pages/dashboard/categories.js)

```javascript
// 1. 初始化时监听全局状态变化
init() {
    // 监听时间区间变化
    window.store.observe('end', () => {
        this.chartData = null;  // 清除缓存
        this.loadChart();       // 重新加载
    });
    
    // 监听主货币转换开关
    window.store.observe('convert_to_primary', (newValue) => {
        this.convertToPrimary = newValue;
        this.loadChart();
    });
}

// 2. 获取数据
getFreshData() {
    const start = new Date(window.store.get('start'));
    const end = new Date(window.store.get('end'));
    
    const dashboard = new Dashboard();
    dashboard.dashboard(start, end, null).then((response) => {
        chartData = response.data;
        this.drawChart(this.generateOptions(chartData));
    });
}

// 3. 前端数据转换（后端返回结构化数据，前端组装成 Chart.js 格式）
generateOptions(data) {
    let options = getDefaultChartSettings('column');
    
    // 按货币和收支类型分组
    let series = {};
    for (const i in data) {
        let current = data[i];
        let code = current.currency_code;
        
        // 创建系列
        for(const type of ['spent', 'earned']) {
            let typeCode = code + '_' + type;
            if (!series[typeCode]) {
                series[typeCode] = {
                    name: typeCode,
                    code: code,
                    type: type,
                    data: {},
                };
            }
        }
        
        // 填充数据
        for(const type of ['spent', 'earned']) {
            let typeCode = code + '_' + type;
            let amount = parseFloat(current.entries[type]);
            
            // 主货币转换时使用 pc_entries
            if(this.convertToPrimary) {
                amount = parseFloat(current.entries.pc_entries[type]);
            }
            
            series[typeCode].data[current.label] = amount;
        }
        
        // X 轴标签
        if (!options.data.labels.includes(current.label)) {
            options.data.labels.push(current.label);
        }
    }
    
    // 4. 组装 Chart.js datasets
    for (const i in series) {
        let dataset = {
            label: i,
            currency_code: currencyCode,
            yAxisID: yAxisID,
            data: [],
        };
        for (const ii in series[i].data) {
            dataset.data.push(series[i].data[ii]);
        }
        options.data.datasets.push(dataset);
    }
    
    return options;
}

// 5. 渲染图表
drawChart(options) {
    if (chart) {
        chart.options = options.options;
        chart.data = options.data;
        chart.update();  // 更新现有图表
        return;
    }
    chart = new Chart(document.querySelector("#category-chart"), options);
}
```

## 七、缓存机制详解

### 7.1 CacheProperties 工作流程

[CacheProperties](file:///d:/fz/0601-1/solo-dogfeeding/code/79-firefly-iii/app/Support/CacheProperties.php)

```
┌─────────────────────────────────────────────────┐
│ 1. 初始化时自动添加                           │
│    - auth()->user()->id                       │
│    - Preferences::lastActivity()              │
│    - Steam::anonymous()                       │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│ 2. 手动添加业务参数                             │
│    $cache->addProperty($start);                │
│    $cache->addProperty($end);                  │
│    $cache->addProperty($category->id);         │
│    $cache->addProperty('chart.category.all');  │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│ 3. 检查缓存                                     │
│    $cache->has()  // 生成哈希并检查             │
└───────────────────┬─────────────────────────────┘
                    │
           ┌────────┴────────┐
           │ 命中            │ 未命中
           ▼                  ▼
    返回缓存数据         执行业务逻辑生成数据
           │                  │
           │      ┌───────────▼───────────┐
           │      │ 4. 存储缓存            │
           │      │    $cache->store($data)│
           │      └───────────┬───────────┘
           │                  │
           └──────────────────┘
                    │
                    ▼
           返回 JSON 响应
```

### 7.2 缓存失效机制

**自动失效**：
- `Preferences::lastActivity()` 记录用户最后活动时间
- 数据变更（创建/更新/删除交易）时更新该时间戳
- 时间戳变化导致缓存哈希变化，原缓存自动失效

**手动失效**：
- 测试环境（`app.env = testing`）直接返回 `false`，跳过缓存
- `Cache::flush()` 清空全部缓存

## 九、关键设计模式与最佳实践

### 9.1 分层架构

| 层级 | 职责 | 代表类 |
|------|------|--------|
| Controller | 参数接收、缓存检查、响应返回 | CategoryController |
| Generator | 业务逻辑编排、数据聚合 | FrontpageChartGenerator |
| Repository | 数据查询封装 | OperationsRepositoryInterface |
| GeneratorInterface | 格式转换（业务格式 → Chart.js 格式） | ChartJsGenerator |

### 9.2 货币处理

1. **字符串存储**：所有金额使用字符串（`bcmath` 函数计算），避免浮点数精度问题
2. **多货币支持**：每种货币独立数据集，前端按货币分组显示
3. **主货币转换**：`ExchangeRateConverter` 实时汇率转换，`pc_entries` 字段存储转换后金额
4. **精度控制**：`Steam::bcround()` 统一处理小数位数

### 9.3 时间处理

1. **粒度自适应**：根据时间跨度自动选择天/周/月/年粒度
2. **时区安全**：所有时间使用 Carbon 对象，统一时区处理
3. **区间对齐**：`startOfPeriod()` / `endOfPeriod()` 确保区间边界正确

### 9.4 性能优化

1. **缓存前置**：控制器入口先检查缓存，未命中才执行业务逻辑
2. **批量查询**：使用 `GroupCollectorInterface` 一次查询所有数据，避免 N+1
3. **前端缓存**：`window.store.set(cacheKey, chartData)` 减少重复请求
