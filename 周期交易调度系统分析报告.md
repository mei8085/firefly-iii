# Firefly III 周期交易调度系统分析报告

## 概述

本报告详细分析了 Firefly III 中周期交易（Recurring Transactions）的调度逻辑，解释周期交易如何按照预定计划被调度器唤醒，并最终生成实际交易记录。

## 系统架构

周期交易系统由以下几个核心组件构成：

1. **Cron 命令层** - `app\Console\Commands\Tools\Cron.php`
2. **CronJob 抽象层** - `app\Support\Cronjobs\AbstractCronjob.php`
3. **RecurringCronjob** - `app\Support\Cronjobs\RecurringCronjob.php`
4. **创建周期交易 Job** - `app\Jobs\CreateRecurringTransactions.php`
5. **RecurringRepository** - `app\Repositories\Recurring\RecurringRepository.php`
6. **数据模型层** - `Recurrence`, `RecurrenceRepetition`, `RecurrenceTransaction`

```php
private function handleRepetitions(Recurrence $recurrence): Collection
{
    $collection = new Collection();

    foreach ($recurrence->recurrenceRepetitions as $repetition) {
        // 计算从 first_date 到 date+2天 范围内的所有发生日期
        $includeWeekend = clone $this->date;
        $includeWeekend->addDays(2);
        $occurrences = $this->repository->getOccurrencesInRange(

            $recurrence->first_date, 
            $includeWeekend
        );

        $result = $this->handleOccurrences($recurrence, $repetition, $occurrences);
        $collection = $collection->merge($result);
    }

    return $collection;
}
```

#### 4.1 getOccurrencesInRange 方法

```php
// RecurringRepository.php 第259-286行
public function getOccurrencesInRange(RecurrenceRepetition $repetition, Carbon $start, Carbon $end): array
{
    $occurrences = [];
    $skipMod = $repetition->repetition_skip + 1;

    if ('daily' === $repetition->repetition_type) {
        $occurrences = $this->getDailyInRange($mutator, $end, $skipMod);
    }
    if ('weekly' === $repetition->repetition_type) {
        $occurrences = $this->getWeeklyInRange($mutator, $end, $skipMod, $repetition->repetition_moment);
    }
    if ('monthly' === $repetition->repetition_type) {
        $occurrences = $this->getMonthlyInRange($mutator, $end, $skipMod, $repetition->repetition_moment);
    }
    if ('ndom' === $repetition->repetition_type) {
        $occurrences = $this->getNdomInRange($mutator, $end, $skipMod, $repetition->repetition_moment);
    }
    if ('yearly' === $repetition->repetition_type) {
        $occurrences = $this->getYearlyInRange($mutator, $end, $skipMod, $repetition->repetition_moment);
    }

    return $this->filterWeekends($repetition, $occurrences);
}
```

#### 4.2 支持的重复类型

| 类型 | 说明 | moment 格式 | 示例 |
|------|------|-------------|------|
| **daily** | 每日 | - | 每隔N天 |
| **weekly** | 每周 | 1-7 (ISO周几) | 每周一 |
| **monthly** | 每月 | 1-31 | 每月15号 |
| **ndom** | 第N个周几 | `N,weekday` | 每月第2个周三 |
| **yearly** | 每年 | Y-m-d | 每年5月1日 |

**文件位置**：[CalculateRangeOccurrences.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Support/Repositories/Recurring/CalculateRangeOccurrences.php)

**每日计算示例**：
```php
protected function getDailyInRange(Carbon $start, Carbon $end, int $skipMod): array
{
    $return = [];
    $attempts = 0;
    while ($start <= $end) {
        if (0 === ($attempts % $skipMod)) {
            $return[] = clone $start;
        }
        $start->addDay();
        ++$attempts;
    }
    return $return;
}
```

**每周计算示例**：
```php
protected function getWeeklyInRange(Carbon $start, Carbon $end, int $skipMod, string $moment): array
{
    $dayOfWeek = (int) $moment;
    // 调整到目标周几
    if ($start->dayOfWeekIso > $dayOfWeek) {
        $start->addWeek();
    }
    $dayDifference = $dayOfWeek - $start->dayOfWeekIso;
    $start->addDays($dayDifference);
    
    while ($start <= $end) {
        if (0 === ($attempts % $skipMod)) {
            $return[] = clone $start;
        }
        $start->addWeek();
    }
    return $return;
}
```

#### 4.3 周末过滤处理

**文件位置**：[FiltersWeekends.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Support/Repositories/Recurring/FiltersWeekends.php)

```php
protected function filterWeekends(RecurrenceRepetition $repetition, array $dates): array
{
    // 不处理周末
    if (RecurrenceRepetitionWeekend::WEEKEND_DO_NOTHING->value === $repetition->weekend) {
        return $dates;
    }
    
    foreach ($dates as $date) {
        if ($date->isWeekend()) {
            // 移动到周五
            if (RecurrenceRepetitionWeekend::WEEKEND_TO_FRIDAY->value === $repetition->weekend) {
                $clone->addDays(5 - $date->dayOfWeekIso);
            }
            // 移动到周一
            if (RecurrenceRepetitionWeekend::WEEKEND_TO_MONDAY->value === $repetition->weekend) {
                $clone->addDays(8 - $date->dayOfWeekIso);
            }
        }
    }
    return $return;
}
```

**周末处理选项**：
- `WEEKEND_DO_NOTHING`：保持周末日期
- `WEEKEND_TO_FRIDAY`：移至周五
- `WEEKEND_TO_MONDAY`：移至周一

### 5. 生成交易记录

**文件位置**：[CreateRecurringTransactions.php](file:///d:/fz/0601-1/solo-dogfeeding/code/52-firefly-iii/app/Jobs/CreateRecurringTransactions.php#L261-L322)

#### 5.1 处理单个发生日期

```php
private function handleOccurrence(Recurrence $recurrence, RecurrenceRepetition $repetition, Carbon $date): ?TransactionGroup
{
    $date->startOfDay();
    if ($date->ne($this->date)) {
        return null; // 只处理今天的日期
    }
    
    // 检查今天是否已创建
    $journalCount = $this->repository->getJournalCount($recurrence, $date, $date);
    if ($journalCount > 0 && false === $this->force) {
        Log::info(sprintf('Already created %d journal(s) for date %s', $journalCount, $date->format('Y-m-d')));
        return null;
    }
    
    // 创建交易数据
    $array = [
        'user'         => $recurrence->user,
        'user_group'   => $recurrence->user->userGroup,
        'group_title'  => $groupTitle,
        'transactions' => $this->getTransactionData($recurrence, $repetition, $date),
    ];
    
    $group = $this->groupRepository->store($array);
    ++$this->created;
    
    // 更新 latest_date
    $this->repository->setLatestDate($recurrence, $date);
    
    return $group;
}
```

#### 5.2 构建交易数据

```php
private function getTransactionData(Recurrence $recurrence, RecurrenceRepetition $repetition, Carbon $date): array
{
    $transactions = $recurrence->recurrenceTransactions()->get();
    $return = [];

    foreach ($transactions as $index => $transaction) {
        $single = [
            'type'           => strtolower((string) $recurrence->transactionType->type),
            'date'           => $date,
            'user'           => $recurrence->user,
            'currency_id'    => $transaction->transaction_currency_id,
            'description'    => $transaction->description,
            'amount'         => $transaction->amount,
            'budget_id'      => $this->repository->getBudget($transaction),
            'category_id'    => $this->repository->getCategoryId($transaction),
            'source_id'      => $transaction->source_id,
            'destination_id' => $transaction->destination_id,
            'tags'           => $this->repository->getTags($transaction),
            'recurrence_id'  => $recurrence->id,
            'recurrence_date'=> $date,
            'notes'          => trans('firefly.created_from_recurrence', [
                'id' => $recurrence->id, 
                'title' => $recurrence->title
            ]),
        ];
        $return[] = $single;
    }

    return $return;
}
```

## 关键配置和限制

### 时间间隔控制
- **最小执行间隔**：12小时（43,200秒）
- **可通过 `--force` 强制执行**

### 重复次数限制
- `repetitions = 0`：无限重复
- `repetitions > 0`：达到次数后停止

### 结束条件
1. 当前日期 > `repeat_until`
2. 执行次数 >= `repetitions`
3. 周期交易被标记为 `active = false`

### 防重复机制
- 检查 `TransactionJournalMeta` 中的 `recurrence_date`
- 如果当天已存在交易，跳过创建（除非 `--force`）

## 触发方式

### 1. 命令行方式（推荐）
```bash
# 标准执行
php artisan firefly-iii:cron
```

## 总结

Firefly III 的周期交易调度系统通过以下机制确保按预定计划执行：

1. **可配置的触发机制**：支持命令行和定时任务触发
2. **执行间隔控制**：防止过度执行
3. **灵活的发生日期计算**：支持5种重复类型和周末处理
4. **多层有效性检查**：确保只创建有效的交易
5. **防重复机制**：避免重复创建同一交易
6. **完整的数据追溯**：通过 journal_meta 关联原周期交易

这套设计确保了周期交易能够可靠、准确地按预定计划执行，同时提供了足够的灵活性来满足各种复杂的需求。
