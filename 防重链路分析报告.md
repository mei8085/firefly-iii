# Firefly III 交易导入：字段映射与重复识别防重链路分析报告

## 1. 概述

Firefly III 通过**字段映射 → 哈希计算 → 重复检测**的三级链路，有效防止同一笔交易被重复入账。本文档深入分析这条防重链路的每个环节及其协作关系。

---

## 2. 整体架构

```
前端表单/导入源
     │
     ▼
┌─────────────────────┐
│  1. 字段映射层       │  将各种来源的字段标准化为统一格式
│  (Field Mapping)    │
└─────────┬───────────┘
          │ 标准化后的数据
          ▼
┌─────────────────────┐
│  2. 哈希计算层       │  对标准化数据生成唯一指纹
│  (Hash Generation)  │  import_hash_v2 = SHA256(JSON(data))
└─────────┬───────────┘
          │ 哈希值
          ▼
┌─────────────────────┐
│  3. 重复检测层       │  查询数据库中是否存在相同哈希
│  (Duplicate Check)  │
└─────────┬───────────┘
          │
    ┌─────┴─────┐
    │           │
  重复         不重复
    │           │
  抛出异常    持久化存储
 (DuplicateTransactionException)
```

## 4. 第二层：哈希计算（Hash Generation）

字段标准化完成后，系统对交易数据生成唯一的 SHA256 哈希指纹。相同内容的交易必将生成相同的哈希。

### 4.1 哈希算法

**核心文件**：[TransactionJournalFactory::hashArray()](file:///d:/fz/0601-1/solo-dogfeeding/code/51-firefly-iii/app/Factory/TransactionJournalFactory.php#L524-L538)

```php
private function hashArray(NullArrayObject $row): string
{
    // 关键：排除不参与哈希计算的字段
    unset($row['import_hash_v2'], $row['original_source']);

    try {
        $json = json_encode($row, JSON_THROW_ON_ERROR);
    } catch (JsonException $e) {
        Log::error(sprintf('Could not encode dataRow: %s', $e->getMessage()));
        $json = microtime();
    }
    // 使用 SHA256 生成哈希
    $hash = hash('sha256', $json);
    Log::debug(sprintf('The hash is: %s', $hash), $row->getArrayCopy());

    return $hash;
}
```

**关键设计要点**：
- 排除 `import_hash_v2` 和 `original_source`，避免递归哈希问题和来源标记干扰
- 先 JSON 编码再哈希，确保字段顺序和类型一致性
- 使用 SHA256 算法，碰撞概率极低

### 5.2 重复检测查询

**核心方法**：[TransactionJournalFactory::errorIfDuplicate()](file:///d:/fz/0601-1/solo-dogfeeding/code/51-firefly-iii/app/Factory/TransactionJournalFactory.php#L419-L444)

```php
private function errorIfDuplicate(string $hash): void
{
    Log::debug(sprintf('In errorIfDuplicate(%s)', $hash));
    // 开关检查：如果关闭则直接返回
    if (false === $this->errorOnHash) {
        return;
    }
    Log::debug('Will verify duplicate!');

    // 查询 journal_meta 表，寻找相同哈希值
    $result = TransactionJournalMeta::withTrashed()
        ->leftJoin('transaction_journals', 'transaction_journals.id', '=', 'journal_meta.transaction_journal_id')
        ->whereNotNull('transaction_journals.id')
        ->where('transaction_journals.user_id', $this->user->id)  // 用户级隔离
        ->where('data', json_encode($hash, JSON_THROW_ON_ERROR))  // 精确匹配哈希
        ->with(['transactionJournal', 'transactionJournal.transactionGroup'])
        ->first(['journal_meta.*']);

    if (null !== $result) {
        Log::warning(sprintf('Found a duplicate in errorIfDuplicate because hash %s is not unique!', $hash));
        $journal = $result->transactionJournal()->withTrashed()->first();
        $group   = $journal?->transactionGroup()->withTrashed()->first();
        $groupId = (int) $group?->id;

        throw new DuplicateTransactionException(sprintf('Duplicate of transaction #%d.', $groupId));
    }
}
```

**查询关键点**：
- 包含软删除记录（`withTrashed()`），防止删除后重新导入相同交易
- 用户级隔离，不同用户的相同交易不算重复
- 精确匹配 `data` 字段中的哈希值

### 6.2 Meta 模型的哈希自动计算

**TransactionJournalMeta** 模型在保存 data 字段时，自动计算其 SHA256 哈希存入 `hash` 列（用于数据库索引加速查询）：

**核心文件**：[TransactionJournalMeta.php](file:///d:/fz/0601-1/solo-dogfeeding/code/51-firefly-iii/app/Models/TransactionJournalMeta.php#L57-L64)

```php
protected function data(): Attribute
{
    return Attribute::make(
        get: static fn ($value): mixed => json_decode((string) $value, false),
        set: static function ($value): array {
            $data = json_encode($value);
            // 自动计算 hash 列，加速后续重复查询
            return ['data' => $data, 'hash' => hash('sha256', $data)];
        }
    );
}
```

**Meta 工厂实现**：[TransactionJournalMetaFactory.php](file:///d:/fz/0601-1/solo-dogfeeding/code/51-firefly-iii/app/Factory/TransactionJournalMetaFactory.php#L36-L77)

```php
public function updateOrCreate(array $data): ?TransactionJournalMeta
{
    $entry = $data['journal']->transactionJournalMeta()->where('name', $data['name'])->first();
    // 空值删除逻辑
    if (null === $value && null !== $entry) {
        $entry->delete();
        return null;
    }
    if ('' === (string) $value) {
        if (null !== $entry) {
            $entry->delete();
        }
        return null;
    }
    // 创建或更新
    if (null === $entry) {
        $entry = new TransactionJournalMeta();
        $entry->transactionJournal()->associate($data['journal']);
        $entry->name = $data['name'];
    }
    $entry->data = $value;  // 触发 Attribute setter，自动计算 hash
    $entry->save();
    return $entry;
}
```

## 9. 防重策略的设计智慧

### 9.1 字段标准化保证哈希一致性
- 所有字段经过类型转换（字符串、整数、浮点、日期对象）
- 缺失字段统一为 `null`（通过 NullArrayObject）
- 字符串经过清洗（trim、特殊字符处理）

### 9.2 双层哈希机制
| 层级 | 位置 | 用途 |
|------|------|------|
| 业务哈希 | `import_hash_v2` 元字段 | 对交易业务数据的 SHA256，用于重复判断 |
| 存储哈希 | `journal_meta.hash` 列 | 对 data 列 JSON 的 SHA256，用于数据库索引加速 |

### 9.3 多维度保护
- **用户隔离**：不同用户的相同交易不算重复
- **软删除感知**：已删除的交易也会阻止重新导入
- **开关控制**：`error_if_duplicate_hash` 允许调用方选择是否启用防重
- **回滚安全**：批量导入中任一笔重复，整批已创建的交易通过 `forceDeleteOnError()` 回滚

**回滚机制**：[TransactionJournalFactory::forceDeleteOnError()](file:///d:/fz/0601-1/solo-dogfeeding/code/51-firefly-iii/app/Factory/TransactionJournalFactory.php#L450-L460)

```php
private function forceDeleteOnError(Collection $collection): void
{
    $service = app(JournalDestroyService::class);
    foreach ($collection as $journal) {
        $service->destroy($journal);  // 级联删除已创建的交易
    }
}
```
