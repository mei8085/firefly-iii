## 一、模块架构概述

### 1.1 核心数据模型

存钱罐功能采用三层数据结构设计：

```
┌─────────────────┐         ┌────────────────────┐         ┌─────────────────┐
│   PiggyBank     │         │ account_piggy_bank │         │      Account    │
│  (存钱罐主体)   │────────▶│  (多对多关联表)    │────────▶│   (账户)        │
├─────────────────┤         ├────────────────────┤         ├─────────────────┤
│ - id            │         │ - account_id       │         │ - id            │
│ - name          │         │ - piggy_bank_id    │         │ - name          │
│ - target_amount │         │ - current_amount   │         │ - user_id       │
│ - start_date    │         │ - native_current_  │         │                 │
│ - target_date   │         │   amount           │         │                 │
└─────────────────┘         └────────────────────┘         └─────────────────┘
           │
           │ 1:N
           ▼
┌──────────────────────────────┐
│      PiggyBankEvent          │

├──────────────────────────────┤
```

## 二、目标金额的设置与更新机制

### 2.1 创建时设置目标金额

**代码位置**：`app/Factory/PiggyBankFactory.php:233-291`

存钱罐创建时通过 `store()` 方法接收并验证目标金额：

```php
public function store(array $data): PiggyBank
{
    $piggyBankData = $data;
    
    // 验证金额：空值转为 "0"
    if (array_key_exists('target_amount', $piggyBankData) 
        && '' === (string) $piggyBankData['target_amount']) {
        $piggyBankData['target_amount'] = '0';
    }
    
    // 设置货币类型
    $piggyBankData['transaction_currency_id'] = $this->getCurrency($data)->id;
    
    // 创建存钱罐
    $piggyBank = PiggyBank::createQuietly($piggyBankData);
    
    // 关联账户
    $this->linkToAccountIds($piggyBank, $data['accounts']);
    
    return $piggyBank;
}
```

**关键设计**：
- 目标金额以字符串形式存储，避免浮点数精度问题
- 支持多货币，通过 `transaction_currency_id` 关联货币类型
- 同时存储本位币等值金额 `native_target_amount` 用于统计

### 2.2 更新时修改目标金额

**代码位置**：`app/Repositories/PiggyBank/ModifiesPiggyBanks.php:367-395`

通过 `updateProperties()` 方法更新目标金额：

```php
private function updateProperties(PiggyBank $piggyBank, array $data): PiggyBank
{
    // ... 其他字段更新
    
    // 设置目标金额
    if (array_key_exists('target_amount', $data) && '' !== $data['target_amount']) {
        $piggyBank->target_amount = $data['target_amount'];
    }
    if (array_key_exists('target_amount', $data) && '' === $data['target_amount']) {
        $piggyBank->target_amount = '0';
    }
    
    // 设置目标日期
    if (array_key_exists('target_date', $data) && '' !== $data['target_date']) {
        $piggyBank->target_date = $data['target_date'];
        $piggyBank->target_date_tz = $data['target_date']?->format('e');
    }
    
    $piggyBank->save();
    return $piggyBank;
}
```

### 2.3 目标金额缩小的自动调整

当更新后的目标金额小于当前已存金额时，系统会自动从关联账户中扣除超出部分：

**代码位置**：`app/Repositories/PiggyBank/ModifiesPiggyBanks.php:303-315`

```php
public function update(PiggyBank $piggyBank, array $data): PiggyBank
{
    $piggyBank = $this->updateProperties($piggyBank, $data);
    
    // ... 其他更新逻辑
    
    // 检查当前金额是否超过新的目标金额
    $currentAmount = $this->getCurrentAmount($piggyBank);
    if (1 === bccomp((string) $currentAmount, (string) $piggyBank->target_amount) 
        && 0 !== bccomp((string) $piggyBank->target_amount, '0')) {
        
        Log::debug(sprintf(
            'Current amount is %s, target amount is %s', 
            $currentAmount, 
            $piggyBank->target_amount
        ));
        
        $difference = bcsub((string) $piggyBank->target_amount, (string) $currentAmount);
        
        // 从所有关联账户中按顺序扣除超出部分
        $this->removeAmountFromAll($piggyBank, Steam::positive($difference));
    }
    
    return $piggyBank;
}
```

**扣除策略**（`removeAmountFromAll()` 方法，第172-186行）：
1. 遍历所有关联账户
2. 如果账户余额大于需扣除金额，扣除后返回
3. 否则扣除账户全部余额，继续处理下一个账户

### 2.4 金额精度处理

系统使用 BC Math 扩展进行高精度计算：

| 函数 | 用途 | 示例 |
|------|------|------|
| `bcadd(a, b)` | 加法 | 计算新的余额 |
| `bcsub(a, b)` | 减法 | 计算差额 |
| `bccomp(a, b)` | 比较 | 比较金额大小 |
| `bcmul(a, b)` | 乘法 | 金额取反 |
| `bcdiv(a, b)` | 除法 | 计算每月建议储蓄额 |

### 3.2 交易关联流程

#### 步骤1：计算关联金额

**代码位置**：`app/Repositories/PiggyBank/PiggyBankRepository.php:185-287`

```php
public function getExactAmount(PiggyBank $piggyBank, TransactionJournal $journal): string
{
    // 1. 判断交易方向（流入/流出）
    $source = $journal->transactions()->where('amount', '<', 0)->first();
    $destination = $journal->transactions()->where('amount', '>', 0)->first();
    
    $operator = null; // positive 或 negative
    $hits = 0;
    
    foreach ($piggyBank->accounts as $account) {
        if ($account->id === $source->account_id) {
            $operator = 'negative'; // 从存钱罐转出
            ++$hits;
        }
        if ($account->id === $destination->account_id) {
            $operator = 'positive'; // 转入存钱罐
            ++$hits;
        }
    }
    
    // 2. 同时匹配源和目标账户时返回0（无法确定方向）
    if ($hits > 1) {
        return '0';
    }
    
    // 3. 计算可操作的最大金额
    $currentAmount = $this->getCurrentAmount($piggyBank);
    $room = bcsub($piggyBank->target_amount, $currentAmount);
    
    // 转入时不能超过剩余额度
    if (1 === bccomp($amount, '0') && -1 === bccomp($room, $amount)) {
        return $room;
    }
    
    // 转出时不能超过当前余额
    if (-1 === bccomp($amount, '0') && 1 === bccomp($compare, $amount)) {
        return $compare;
    }
    
    return $amount;
}
```

#### 步骤2：更新关联表余额

**代码位置**：`app/Repositories/PiggyBank/ModifiesPiggyBanks.php:52-73`

```php
public function addAmount(
    PiggyBank $piggyBank, 
    Account $account, 
    string $amount, 
    ?TransactionJournal $journal = null
): bool {
    // 获取当前余额
    $currentAmount = $this->getCurrentAmount($piggyBank, $account);
    
    // 更新关联表
    $pivot = $piggyBank->accounts()->where('accounts.id', $account->id)->first()->pivot;
    $pivot->current_amount = bcadd((string) $currentAmount, $amount);
    
    // 更新本位币金额
    $userCurrency = Amount::getPrimaryCurrencyByUserGroup($this->user->userGroup);
    if ($userCurrency->id !== $piggyBank->transaction_currency_id) {
        $converter = new ExchangeRateConverter();
        $converter->setIgnoreSettings(true);
        $pivot->native_current_amount = $converter->convert(
            $piggyBank->transactionCurrency, 
            $userCurrency, 
            today(), 
            $pivot->current_amount
        );
    }
    
    $pivot->save();
    
    // 触发金额变动事件
    event(new PiggyBankAmountIsChanged($piggyBank, $amount, $journal, null));
    
    return true;
}
```

```php
class CreatesPiggyBankEventForChangedAmount implements ShouldQueue
{
    public function handle(PiggyBankAmountIsChanged $event): void
    {
        // 获取关联交易
        $journal = $event->transactionJournal;
        if ($event->transactionGroup instanceof TransactionGroup) {
            $journal = $event->transactionGroup->transactionJournals()->first();
        }
        
        $date = $journal->date ?? today(config('app.timezone'));
        
        // 防重复：检查是否已存在相同关联
        if (null !== $journal) {
            $exists = PiggyBankEvent::where('piggy_bank_id', $event->piggyBank->id)
                ->where('transaction_journal_id', $journal->id)
                ->exists();
            if ($exists) {
                Log::warning('Already have event for this journal and piggy, will not create another.');
                return;
            }
        }
        
        // 创建事件记录
        PiggyBankEvent::create([
            'piggy_bank_id' => $event->piggyBank->id,
            'transaction_journal_id' => $journal?->id,
            'date' => $date->format('Y-m-d'),
            'date_tz' => $date->format('e'),
            'amount' => $event->amount,
        ]);
    }
}
```

### 3.3 账户关联管理

**代码位置**：`app/Factory/PiggyBankFactory.php:104-199`

```php
public function linkToAccountIds(PiggyBank $piggyBank, array $accounts): void
{
    $toBeLinked = [];
    $oldSavedAmount = $this->piggyBankRepository->getCurrentAmount($piggyBank);
    
    // 保留已有账户的当前金额
    foreach ($piggyBank->accounts as $account) {
        foreach ($accounts as $info) {
            if ((int) $account->id === (int) $info['account_id']) {
                $toBeLinked[$account->id] = [
                    'current_amount' => $account->pivot->current_amount ?? '0'
                ];
            }
        }
    }
    
    // 处理新关联或金额变更
    foreach ($accounts as $info) {
        $account = $this->accountRepository->find((int) ($info['account_id'] ?? 0));
        if (!$account instanceof Account) {
            continue;
        }
        
        if (array_key_exists('current_amount', $info) && null !== $info['current_amount']) {
            $previous = $toBeLinked[$account->id]['current_amount'] ?? '0';
            $diff = bcsub($info['current_amount'], $previous);
            
            // 验证是否可以添加金额
            if (1 === bccomp($diff, '0') 
                && !$this->piggyBankRepository->canAddAmount($piggyBank, $account, $diff)) {
                continue;
            }
            
            $toBeLinked[$account->id] = ['current_amount' => $info['current_amount']];
        }
    }
    
    // 执行同步
    if (0 !== count($toBeLinked)) {
        $piggyBank->accounts()->sync($toBeLinked);
        $piggyBank->refresh();
        
        // 总额变化时触发事件
        $newSavedAmount = $this->piggyBankRepository->getCurrentAmount($piggyBank);
        if (0 !== bccomp($oldSavedAmount, $newSavedAmount)) {
            event(new PiggyBankAmountIsChanged(
                $piggyBank, 
                bcsub($newSavedAmount, $oldSavedAmount), 
                null, 
                null
            ));
        }
    }
}
```

## 四、图表数据计算流程

### 4.1 图表控制器入口

**代码位置**：`app/Http/Controllers/Chart/PiggyBankController.php:63-106`

```php
public function history(PiggyBankRepositoryInterface $repository, PiggyBank $piggyBank): JsonResponse
{
    // 1. 检查缓存
    $cache = new CacheProperties();
    $cache->addProperty('chart.piggy-bank.history');
    $cache->addProperty($piggyBank->id);
    if ($cache->has()) {
        return response()->json($cache->get());
    }
    
    // 2. 获取事件数据
    $set = $repository->getEvents($piggyBank);
    $set = $set->reverse(); // 按时间升序
    
    // 3. 确定时间范围
    $startDate = $piggyBank->start_date ?? today(config('app.timezone'));
    $firstEvent = $set->first();
    $firstDate = null === $firstEvent ? new Carbon() : $firstEvent->date;
    $oldest = $startDate->lt($firstDate) ? $startDate : $firstDate;
    $today = today(config('app.timezone'));
    
    // 4. 计算时间步长
    $step = $this->calculateStep($oldest, $today);
    
    // 5. 生成数据点
    $chartData = [];
    while ($oldest <= $today) {
        $filtered = $set->filter(static fn (PiggyBankEvent $event) => $event->date->lte($oldest));
        $currentSum = $filtered->sum('amount');
        $label = $oldest->isoFormat((string) trans('config.month_and_day_js', [], $locale));
        $chartData[$label] = $currentSum;
        $oldest = Navigation::addPeriod($oldest, $step);
    }
    
    // 6. 确保最后一个数据点是今天
    $finalFiltered = $set->filter(static fn (PiggyBankEvent $event) => $event->date->lte($today));
    $finalSum = $finalFiltered->sum('amount');
    $finalLabel = $today->isoFormat((string) trans('config.month_and_day_js', [], $locale));
    $chartData[$finalLabel] = $finalSum;
    
    // 7. 格式化输出并缓存
    $data = $this->generator->singleSet($piggyBank->name, $chartData);
    $cache->store($data);
    
    return response()->json($data);
}
```

### 4.2 时间步长计算

**代码位置**：`app/Support/Http/Controllers/DateCalculation.php`

```php
protected function calculateStep(Carbon $start, Carbon $end): string
{
    $days = $start->diffInDays($end);
    
    if ($days <= 14) {
        return '1D';      // 1天（≤2周）
    }
    if ($days <= 60) {
        return '1W';      // 1周（≤2个月）
    }
    if ($days <= 365) {
        return '1M';      // 1个月（≤1年）
    }
    return '1Y';          // 1年（>1年）
}
```

## 五、撤销关联交易后的一致性保证

### 5.1 交易删除时的关联处理

**代码位置**：`app/Handlers/Observer/DeletedTransactionJournalObserver.php:38-81`

```php
public function deleting(TransactionJournal $transactionJournal): void
{
    Log::debug('Observe "deleting" of a transaction journal.');
    
    // ... 删除其他关联数据
    
    // 关键：仅解除关联，不删除事件记录，不调整金额
    $transactionJournal->piggyBankEvents()->update(['transaction_journal_id' => null]);
    
    // ... 删除其他关联数据
}
```

**处理策略**：
- ✅ 将 `piggy_bank_events.transaction_journal_id` 设为 NULL
- ❌ 不删除 `PiggyBankEvent` 记录
- ❌ 不调整 `account_piggy_bank.current_amount`
- ❌ 不重新计算图表数据

### 5.2 数据一致性分析

| 数据项 | 删除交易后状态 | 一致性 |
|--------|---------------|--------|
| `PiggyBankEvent` 记录 | 保留，`transaction_journal_id` 为 NULL | 历史完整 |
| `account_piggy_bank.current_amount` | 不变 | ⚠️ 可能不一致 |
| 图表数据 | 不变（基于事件累加） | ✅ 与事件一致 |
| 交易追溯能力 | 丢失关联 | ⚠️ 无法追溯 |

### 5.3 手动重置机制

当需要恢复数据一致性时，用户可调用重置历史功能：

**代码位置**：`app/Repositories/PiggyBank/PiggyBankRepository.php:412-420`

```php
public function resetHistory(PiggyBank $piggyBank): void
{
    // 1. 删除所有事件记录
    $piggyBank->piggyBankEvents()->delete();
    
    // 2. 为每个账户的当前余额创建新事件
    foreach ($piggyBank->accounts as $account) {
        if (0 !== bccomp('0', (string) $account->pivot->current_amount)) {
            event(new PiggyBankAmountIsChanged(
                $piggyBank, 
                $account->pivot->current_amount, 
                null, 
                null
            ));
        }
    }
}
```

**重置效果**：
- 清除所有历史事件
- 以当前余额为基准创建新的起始事件
- 图表数据从当前时间点重新开始累积
- 丢失历史变动细节，但保证当前状态一致

### 5.4 定期清理机制

系统提供定期清理命令处理软删除数据的关联：

**代码位置**：`app/Console/Commands/Correction/RemovesLinksToDeletedObjects.php`

```php
public function handle(): void
{
    $deletedJournals = TransactionJournal::withTrashed()
        ->whereNotNull('deleted_at')
        ->get('transaction_journals.id')
        ->pluck('id')
        ->toArray();
    
    if (count($deletedJournals) > 0) {
        $this->cleanupJournals($deletedJournals);
    }
    
    // ... 清理其他类型
}

private function cleanupJournals(array $journals): void
{
    foreach (array_chunk($journals, 1337) as $set) {
        DB::table('tag_transaction_journal')->whereIn('transaction_journal_id', $set)->delete();
        DB::table('budget_transaction_journal')->whereIn('transaction_journal_id', $set)->delete();
        DB::table('category_transaction_journal')->whereIn('transaction_journal_id', $set)->delete();
    }
}
```

**注意**：该命令清理标签、预算、分类的关联，但**不处理存钱罐事件的关联**。

### 5.5 设计权衡分析

**保留历史记录的原因**：
1. **审计追踪**：即使交易删除，资金变动历史仍可追溯
2. **图表连续性**：图表不会因交易删除出现断崖式下跌
3. **用户预期**：手动存入的金额不应因关联交易删除而消失

**潜在问题**：
1. **数据漂移**：存钱罐余额与实际账户余额可能出现差异
2. **追溯困难**：无法通过交易找到对应的存钱罐变动
3. **需手动干预**：用户需理解并使用重置功能

## 六、总结与设计评价

### 6.1 核心设计模式

| 模式 | 应用场景 | 优点 |
|------|---------|------|
| **事件溯源 (Event Sourcing)** | 金额变动通过 `PiggyBankEvent` 记录 | 完整历史、可审计、可重放 |
| **仓库模式 (Repository)** | `PiggyBankRepository` 封装数据访问 | 解耦业务逻辑与数据层 |
| **观察者模式 (Observer)** | 模型事件监听（创建、更新、删除） | 横切关注点分离 |
| **事件-监听者** | `PiggyBankAmountIsChanged` 事件与监听器 | 异步处理、解耦 |

### 6.2 优点

1. **高精度计算**：使用 BC Math 避免浮点数精度问题
2. **多货币支持**：同时存储原币和本位币金额
3. **多账户关联**：一个存钱罐可关联多个账户
4. **历史完整性**：事件记录保留所有变动历史
5. **缓存优化**：图表数据支持缓存提升性能

### 6.3 改进建议

1. **交易删除时的可选策略**：
   ```php
   // 建议增加配置项支持不同策略
   $strategy = config('firefly.piggy_bank.delete_strategy', 'keep_history');
   // 'keep_history' - 保留历史（当前行为）
   // 'rollback' - 回滚金额变动
   // 'prompt' - 提示用户选择
   ```

2. **一致性检查命令**：
   ```php
   // 建议增加定期校验命令
   public function verifyConsistency(PiggyBank $piggyBank): bool
   {
       $eventSum = $piggyBank->piggyBankEvents()->sum('amount');
       $currentAmount = $this->getCurrentAmount($piggyBank);
       return 0 === bccomp($eventSum, $currentAmount);
   }
   ```

3. **软删除关联支持**：
   在 `PiggyBankEvent` 上使用软删除，便于恢复。
